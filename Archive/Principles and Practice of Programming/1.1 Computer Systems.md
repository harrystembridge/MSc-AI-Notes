## Hardware
- There are 3 main types of computers (increasing in size):
	1. PCs
	2. Workstations
	3. Mainframes
- Computers have 5 main components:
	1. Input devices - allow you to communicate information to the computer
	2. Output devices - allow the computer to communicate information to you
	3. The processor (CPU) 
	4. Main memory (RAM)
	5. Secondary memory (storage)
![[Main Components of a Computer.png]]

## High-Level Languages
**High-level Languages**
#card 
High-level languages resemble human languages. These include C++, C, C#, Java, Python, PHP, Pascal, Visual Basic, FORTRAN, COBOL, Lisp, Scheme and Ada. They are designed to be relatively easy for humans to write programs and equally easy for humans to read. 
^q-har6

Computers can only understand low-level languages, e.g. assembly language. Even assembly language must be translated before the computer can understand into 1s and 0s, this is known as machine language. This is the version of the program that the computer actually reads and follows.

Any high-level language must be translated to machine language before the computer can understand or follow it.

## Compilers
**Compilers**
#card 
Compilers are programs that translate a high-level language like C++ to machine language.
^q-tesg

The input program for a compiler is called the **source program** or **[[source code]]**, and the output of the compiler is the **object program** or **[[object code]]**.

[[source code]] ⇒ [[object code]]

Items that have already been programmed, such as input and output routines, are already compiled. They are waiting to be combined with your program to produce a complete machine-language program that can be run on the computer. 

**Linker**
#card 
A linker combines the [[object code]] for pre-programmed routines, such as input and output, with your own object code from the compiler. The process of combining your object code with the pre-programmed object code is known as linking. Often, linking is done for you automatically.
^q-dmdk
