## A Sample C++ Program
```cpp
#include <iostream> //an include directive, tells the compiler where to find information about certain items used in the program
using namespace std; //this line tells us that the names defined in iostream are to be interpreted in the standard way
int main() //this defines the main function of the program
{
	int numberOfPods, peasPerPod, totalPeas; //variable declaration
	cout << "Enter number of pods:\n"; //output, arrows show the direction of travel of data
	cin >> numberOfPods; //input, again arrows showing data moving
	cout << "Enter the number of peads in a pod: \n";
	cin >> peasPerPod;
	totalPeas = peasPerPod * numberOfPods; //semicolon is end of statement
	cout << totalPeas << "\n";
	return 0;
}
```
