## Algorithms
**Algorithm**
#card 
An algorithm is a sequence of precise instructions which leads to a solution - also known as a recipe, method, directions, procedure or routine.
^q-r2d6

Instructions may well be in terms of a programming language or a human language. 

A computer program is simply an algorithm expressed in a language that a computer can understand.

## Program Design
Program design can be broken into 2 phases:
1. The problem solving phase - determine an algorithm written in English
2. The implementation phase - produce a final program from the algorithm

## Object-Oriented Programming
Modern programs are often designed using **OOP** or **object-orientated programming**. In OOP, a program is a collection of interacting objects. 

The main characteristics of OOP are:
1. Encapsulation - a form of information hiding or abstraction. It simplifies the description of objects.
2. Inheritance - writing reusable program code.
3. Polymorphism - A single name can have multiple meanings in the context of inheritance.

C++ accommodates OOP through classes.
